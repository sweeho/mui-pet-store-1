# Order fulfilment

## Why
Recover the behaviour of supplier purchase-order creation, stock-based fulfilment, invoicing and order status tracking from the legacy application so it can be rebuilt and verified.

## What changes
- Specifies 51 recovered requirements (11 approved, 40 awaiting review) under one capability, `order-fulfilment`, including the supplier inventory screen.
- Covers purchase order and line item records, status lifecycle, fulfilment against stock, invoice processing, identifier counters and the supporting indexes.

## Impact
New capability; no existing spec is modified.
